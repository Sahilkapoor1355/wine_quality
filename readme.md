🍷 Wine Quality Prediction App

A Machine Learning web application built using Python and Streamlit to predict wine quality based on its physicochemical properties.

🚀 Features

Predict wine quality using a trained Machine Learning model.

Interactive interface built with Streamlit.

Accepts 11 chemical properties as input.

Instant prediction results.

Simple and user-friendly design.

🧪 Input Features

Fixed Acidity

Volatile Acidity

Citric Acid

Residual Sugar

Chlorides

Free Sulfur Dioxide

Total Sulfur Dioxide

Density

pH

Sulphates

Alcohol

🛠️ Technologies Used

Python

NumPy

Joblib

Streamlit

Scikit-learn

⚙️ Installation

Clone the repository:

git clone https://github.com/sahilkapoor1355/wine_quality.git

Navigate to the project directory:

cd wine_quality

Install the dependencies:

pip install -r requirements.txt

▶️ Run the Application

streamlit run wine_quality_app.py

📊 How It Works

Enter the required wine chemical properties.

Click the Predict Quality button.

The Machine Learning model processes the inputs.

View the predicted wine quality.

🎯 Purpose

This project demonstrates the integration of a Machine Learning model with a web interface using Streamlit, making wine quality prediction simple and interactive.

Developed using Python and Machine Learning.
